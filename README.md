## 🧑‍💻 Sobre mim

Sou desenvolvedor Full-Stack com foco no ecossistema **JavaScript/TypeScript**: **React e Next.js** no front-end, **Node.js e Express** no back-end. Paralelamente, trabalho com **automação robótica de processos (RPA)**, desenhando fluxos que conectam planilhas, sistemas internos e robôs para eliminar trabalho manual e repetitivo.

Gosto de código organizado e testável, e venho aprofundando **POO** e **Domain-Driven Design** para construir sistemas que continuem fáceis de manter conforme crescem.

- 🌱 Estudando: **Next.js, Node.js, Docker, PostgreSQL, POO e DDD**
